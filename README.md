# Shingeki_nK

Extensión de VS Code para generar proyectos de software usando la CLI **Shingeki_nK**.

## Requisitos

Tener instalado el paquete `shingeki_nk` en tu sistema:
```bash
dotnet tool install -g shingeki_nk
```

## Comandos

| Comando | Descripción |
|---|---|
| `Shingeki_nK: Init proyecto` | Inicia el asistente interactivo para crear un archivo `.scf` |
| `Shingeki_nK: Build .scf` | Compila un archivo `.scf` y genera la estructura del proyecto |

## Uso

1. Abre la paleta de comandos con `Ctrl+Shift+P`
2. Escribe `Shingeki_nK` y selecciona el comando deseado
